## 1. Full-Stack Web App: Customer Loyalty & Venue Management
**Live App:** https://app.micacatania.it/
**Role:** Full-Stack Developer & Architect

I designed and built a comprehensive web application from scratch for a local venue to handle customer retention and digital menu management.

*   **Tech Stack:** Next.js, React, Tailwind CSS, Supabase.
*   **Architecture & Features:** 
    *   **Frontend:** Developed a fully responsive and interactive UI using Next.js and React, featuring complete multi-language support.
    *   **Backend & Auth:** Integrated Supabase for secure user authentication and relational database management.
    *   **Core Logic:** Built a custom digital fidelity point tracking system for customers.
    *   **Admin Tools:** Created a secure back-office dashboard allowing the management to update menus and track data dynamically.
*   **Workflow:** Handled the entire product lifecycle—from database schema design and AI-assisted component development to final testing and production deployment.

## 2. Web Infrastructure & E-Commerce Management
**Organization:** Euracus S.r.l. - Impresa sociale / AreaSud  
**Role:** Head of IT & Web Manager

I manage the digital infrastructure, e-commerce platforms and server environments for a large network of cultural festivals and commercial entities (including euracus.it, duesiciliaefestival.it, areasud.it, musicasacracatania.it and zampognarea.it).

*   **Tech Stack:** Linux Hosting, WordPress, WooCommerce, Elementor, Custom CSS.
*   **Architecture & Features:**
    *   **System Administration:** Set up and manage Linux hosting environments. Handled complex domain migrations, such as moving legacy Windows server setups to Linux environments.
    *   **E-Commerce Setup:** Structured the homepage and launched the WooCommerce shop for Euracus S.r.l., managing digital product catalogs and preparing systems for online ticket sales.
    *   **Network Integration:** Designed the digital hub architecture to seamlessly link multiple festival websites, implementing custom post types and standardized layouts for venues.
*   **Workflow:** Focused on security, performance optimization, and translating complex business/event requirements into scalable web platforms.
